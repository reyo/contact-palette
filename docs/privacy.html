PRIVACY POLICY · UPDATED NOVEMBER 12, 2026

Your contacts
stay on your PC.

Contact Palette is an independent, open-source extension for Microsoft PowerToys Command Palette. It searches local Mozilla Thunderbird address books.

What the extension reads

The extension discovers Thunderbird profiles for the current Windows user and opens supported address book databases through SQLite read-only, query-only connections. It reads contact names, email addresses, phone numbers, available detail fields, and photos already stored locally. Parsed contacts and photos are kept in memory; Contact Palette does not create a separate contact index or photo cache.

What leaves your computer

The extension does not upload contacts or connect to remote contact servers. It does not download remote photos or include telemetry, advertising, tracking SDKs, or remote API calls.

  • Copy: only the value you choose is placed on the Windows clipboard. Windows clipboard history and cloud clipboard, if you enable them, follow your Windows settings.
  • Compose email: the chosen address is passed as a mailto link to your default mail application. That application controls drafting, sending, and its own network access. Contact Palette does not send the email.

Your data stays under your control

Editing or deleting contacts and synchronizing CardDAV address books remain under Thunderbird’s control. The extension requires runFullTrust to read files outside its installation directory. The absence of an internetClient capability does not technically restrict networking for a full-trust desktop process; the offline behavior is implemented in the application code.

This website

This website uses no analytics, advertising, external fonts, cookies set by its own code, or contact-data requests. Its interactive preview contains fictional example contacts and runs entirely in your browser. It reads no address books. If you use a Copy button, the displayed sample text is copied to your clipboard.

The site is hosted by GitHub Pages. GitHub may process technical request information, including IP addresses, to operate its service. See the GitHub Privacy Statement for hosting-related processing. Following a GitHub link takes you to GitHub.

Diagnostics and support

The optional local diagnostic reports counts rather than contact values. Do not include actual address books, private profile paths, or screenshots containing real contacts in public issue reports. Use fictional examples.

For questions about this project, open a GitHub issue without including personal contact data. Source code and the repository privacy policy are available at reyo/contact-palette.
