LOCAL BY DESIGN

Your address book.
Still yours.

Contact Palette reads what Thunderbird has already saved on your computer. Your contacts don’t need to take a detour through someone else’s server.

Read the privacy policy ↗
↳

Read-only access

Searches your local SQLite address books without editing your Thunderbird contacts.

◎

No telemetry. No contact uploads.

No tracking, account sign-in, or remote photo downloads in the extension.

⇄

Your synced contacts, too

Includes CardDAV contacts already synchronized locally by Thunderbird. No separate server connection.

Try the development preview

You’ll need Windows 11, PowerToys with Command Palette enabled, and Thunderbird with local address books.

  1. Install the .NET 10 SDK and Windows SDK tools as described in the README.
  2. Enable Windows Developer Mode and clone the repository.
  3. Run the local installer from the project directory:
.\install-local.ps1

The current preview is a development installation. Microsoft Store and WinGet releases are not available yet.
