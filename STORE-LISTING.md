# Draft Microsoft Store listing

**Name:** Contact Palette

**Short description:** Find, copy and email Thunderbird contacts right from PowerToys Command Palette.

**Description:**

Contact Palette brings your Thunderbird address books into Microsoft PowerToys Command Palette. Search names, email addresses and phone numbers, copy an address in one keystroke, or start an email without opening the address book.

Your contacts stay on your PC. Contact Palette reads Thunderbird's local address books in read-only mode, including locally synchronized CardDAV contacts. It does not upload contacts, run analytics, require cloud accounts, or install a Thunderbird add-on.

Select a contact to preview all available details in the side panel, including contact photos already stored locally, email addresses, phone numbers, organization, job title, postal addresses and notes. Remote contact images are not downloaded.

**Requires:** Windows 11, Microsoft PowerToys with Command Palette enabled, and Mozilla Thunderbird with local address books.

**Notes:** Contact Palette is an independent, open-source community project, not an official Mozilla Thunderbird or Microsoft product.

Before using this text for Store publication, complete Windows integration testing and verify the claims against the final release package. Store screenshots must come from the actual installed application.
